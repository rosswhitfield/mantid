- New algorithm :ref:`algm-LoadEventNexusMD` loads single crystal diffraction event data from a NeXus file straight into an ``MDEventWorkspace`` in ``Q_sample`` or ``Q_lab``, without building an intermediate ``EventWorkspace``. It is the equivalent of :ref:`algm-LoadEventNexus` followed by :ref:`algm-ConvertToMD` and produces identical output for the same extents, but is around a third faster and uses appreciably less memory.
