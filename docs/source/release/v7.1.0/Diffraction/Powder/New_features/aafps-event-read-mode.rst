- :ref:`algm-AlignAndFocusPowderSlim` has a new ``EventReadMode`` property. ``Direct`` reads the events straight from the file on many threads instead of through the HDF5 library, and ``DirectFileOrder`` also reads all banks in one pass in file order, which is faster on network file systems such as the SNS GPFS storage. The default, ``HDF5``, is unchanged, and every mode gives identical results.
